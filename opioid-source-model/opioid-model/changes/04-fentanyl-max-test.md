One of the authors' two test runs. Fentanyl multiplies the overdose rate of people using heroin, up to a maximum the calibration estimated; this switches to a fixed test maximum of 7 instead, to see how much the results depend on that estimate.

Unlike a policy, this changes history too: the fitted values were estimated with the old cap, so the run no longer matches the data from the mid-2010s on.
